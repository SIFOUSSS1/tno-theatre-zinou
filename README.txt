TNO — ADMIN + SITE CONNECTED

1) Ouvrir PowerShell dans:
   TNO_ADMIN_SYSTEM\TNO_ADMIN_SERVER

2) Lancer:
   npm start

Aucun npm install n'est nécessaire: le serveur utilise uniquement Node.js natif.

3) Ouvrir:
   Site:  http://127.0.0.1:3030
   Admin: http://127.0.0.1:3030/admin

Admin:
   Email: newthatertno@gmail.com
   Mot de passe: Zinoutno2018

Tout est servi par le même serveur:
- commandes de livres -> data/orders.json -> Admin
- inscriptions -> data/applications.json -> Admin
- articles/presse, agenda, spectacles, galerie, livres -> données JSON -> site officiel
- modifications depuis Admin -> visibles sur le site après actualisation

Ne pas ouvrir le site avec Live Server si vous voulez tester la connexion complète.
